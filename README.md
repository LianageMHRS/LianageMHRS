## 🚀 Featured Projects

#### [🎯 AI-Based Cricket Training App](https://github.com/LianageMHRS/cricket-ai-training)
An integrated AI-assisted platform delivering structured coaching feedback through video analysis.
- 82% accuracy across 7 cricket shot types using EfficientNetB4
- Real-time video analysis, instant player feedback, AI-powered coaching via Google Gemini
- `Python` `TensorFlow/Keras` `FastAPI` `Celery` `Docker`

#### [💰 Personal Finance Tracker Backend](https://github.com/LianageMHRS/personal-finance-tracker)
Secure RESTful API for managing income, expenses, and financial goals with intelligent notifications.
- JWT auth, RBAC, recurring transactions, tag-based categorization
- Comprehensive testing with Jest, security best practices with bcrypt
- `Node.js` `Express.js` `MongoDB` `REST API` `Jest`

#### [🎪 Event & Resource Management Platform](https://github.com/LianageMHRS/EventIQ)
Microservice-based platform with real-time notifications and role-based access control.
- Complete microservice architecture, Kubernetes orchestration, Azure deployment with CI/CD
- Kafka-based messaging, inter-service communication patterns
- `Node.js` `Spring Boot` `FastAPI` `React` `Kafka` `Docker` `Kubernetes` `Azure`

#### [🌍 REST Countries App](https://rest-countries-hosting-1286.vercel.app/)
Responsive React SPA exploring and filtering country information with dynamic interactions.
- Integrated REST API, search/filter functionality, session management
- Unit and integration tests with Jest and React Testing Library
- `React.js` `Tailwind CSS` `Vercel` `Jest`

#### [🔌 EV Charging Station Booking System](https://github.com/LianageMHRS/EVChargingSystem)
Client–server platform for EV booking serving web and mobile applications.
- EV Owner Management across web and mobile with NIC-based identification
- Mobile SQLite synchronization with central server
- `C#` `MongoDB` `Kotlin` `Android` `React.js` `REST APIs`

#### [📊 Entertainment Rating Prediction System](https://github.com/LianageMHRS/ml-entertainment-rating-analysis)
ML module predicting anime ratings with regularization and feature engineering.
- Linear Regression, Ridge Regression (L2), SGD Regressor with cross-validation
- Data preprocessing, dimensionality reduction via SVD
- `Python` `Scikit-learn` `Pandas` `NumPy` `Matplotlib`
